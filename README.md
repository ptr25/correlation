# Coffee & Sleep Correlation Analysis

A Python project exploring the relationship between coffee consumption and sleep duration using statistical analysis and interactive visualization.

## Features
- CSV dataset processing
- Pearson's correlation coefficient using NumPy
- Interactive scatter plots using Plotly

## Run Locally

```bash
pip install numpy plotly pandas
python coffeeCorrelation.py
```

## Results

The dataset demonstrates a strong negative correlation between coffee consumption and sleep duration.

## Tech Stack

Python · NumPy · Plotly · CSV
